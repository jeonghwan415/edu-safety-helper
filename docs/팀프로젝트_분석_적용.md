# 팀 프로젝트(테크브리프) 분석과 개인 프로그램 적용 (2026-11-24)

대상: 5조 팀 프로젝트 **테크브리프** (`khyun-0123/cheonan-ax-project`, 배포 https://cheonan-ax-project-production.up.railway.app/)
적용한 곳: 프로그램 서포터 · 6대 의무교육 도우미 · 차량 지킴이

## 1. 팀 프로젝트에 들어간 기술·기능

| 구분 | 내용 | 파일 |
|---|---|---|
| 구성 | React 19 + Vite 화면, 같은 포트의 Node API 서버, PostgreSQL, Railway 배포 | `src/`, `server/`, `docs/43_deploy_gcp_railway_team5.md` |
| 접속 보호 | **접속 코드 문**: 코드를 한 번 넣으면 30일 쿠키, 틀린 코드는 IP마다 15분에 10번까지, 코드는 해시로만 보관 | `server/accessGate.js` |
| 관리자 로그인 | 비밀번호 해시(scrypt), 8시간 세션, 잠금 리셋 계정 | `server/admin.js`, `server/credentials.js` |
| 처음 온 사람 안내 | **사용 안내 투어**: 실제 화면 요소를 차례로 밝히고 옆에 설명 카드, → · Enter 다음 / ← 이전 / Esc 닫기, 한 번 보면 기억, 「? 사용 안내」로 다시 보기 | `src/GuideTour.jsx` |
| 화면 설정 | **라이트·다크** 전환(브라우저에 기억), 페이지 확대 보정 | `src/theme.js`, `src/SettingsMenu.jsx`, `src/utils.js` |

| 팀 공유 | 보고서함 **팀 공유**, 만든 사람 표시, 휴지통 | `src/ReportArchive.jsx` |
| 자리 옮기기 | 브라우저에 묶인 자료를 **파일로 내보내고 새 PC에서 불러오기** | `src/DataMove.jsx` |
| 진행 표시 | 오른쪽 아래 진행 창(기사별·전체 게이지, 재시도) | `src/ProgressPanel.jsx` |
| 디자인 원칙 | 토큰으로만 값 지정, **한 화면에 기본 버튼 하나**, 지우기·취소는 오른쪽 빨간 글자, 동작 줄이기(`prefers-reduced-motion`), 본문 대비 4.5:1 | `docs/20_design_system_team5.md`, `src/tokens.css` |
| 품질 | Storybook 부품 정리, oxlint, 형태소 분석(Kiwi) | `.storybook/`, `src/stories/` |

## 2. 개인 프로그램에 적용한 것

| 팀 기능 | 개인 프로그램에 맞게 바꾼 것 | 적용 |
|---|---|---|
| 접속 코드 문 + 시도 제한 | **센터 초대 코드**(8자리, 헷갈리는 글자 뺌). 틀리면 15분에 10번까지(서버 함수), 로그인 5번 틀리면 5분 잠금(화면). 센터장이 코드를 새로 만들면 예전 코드는 막힘 | 세 프로그램 |
| 관리자 로그인 · 팀 공유 | **센터 계정(B)**: Supabase 로그인 + 센터별 행 단위 보안(RLS). 센터장/선생님 역할, 선생님 내보내기 | 세 프로그램 |
| 만든 사람 표시 · 기록 | 서버가 **누가 언제 추가·수정·삭제했는지** 자동 기록 → 센터 창 「최근에 고친 기록」, 다른 선생님이 고치면 "김선생 선생님이 고쳤어요" 알림 | 세 프로그램 |
| AI·DB 연결 상태 점 | 머리말 **저장 상태 단추**: 이 컴퓨터에만 저장(노랑) / ○○센터 · 함께 저장(초록) / 연결 끊김(빨강). 누르면 계정 창 | 세 프로그램 |
| 사용 안내 투어 | 같은 방식(밝히기 + 카드 + 키보드)으로 다시 만들어 **처음 한 번 자동**, 「? 사용 안내/둘러보기」로 다시 보기 | 세 프로그램 |
| 라이트·다크 | **화면 자동/밝게/어둡게** 단추 (원래 다크 색이 있던 두 프로그램) | 프로그램 서포터, 차량 지킴이 |
| 페이지 확대 | 40~50대 선생님 의견에 맞춰 **글자 보통/크게/아주 크게** 단추(1.0·1.12·1.25배, 기억) | 세 프로그램 |
| 자리 옮기기 | 센터 계정으로 들어갈 때 이 컴퓨터 기록을 **합치기 / 합치지 않기(파일로 받기)** 선택 | 세 프로그램 |
| 진행 창 · 재시도 | 인터넷이 끊기면 그 컴퓨터에 보관 → 연결되면 자동으로 다시 보냄 | 세 프로그램 |
| 디자인 원칙 | 새 창은 기본 버튼 하나(검정), 로그아웃·내보내기는 빨간 글자, 누르는 곳 44px 이상, 동작 줄이기 존중, 인쇄할 때 숨김 | 세 프로그램 |

## 3. 가져오지 않은 것과 이유

| 팀 기능 | 이유 |
|---|---|
| React·Vite·Node 서버 | 개인 프로그램은 **파일 하나로 더블클릭해도 열리는 것**이 장점. 서버를 두면 운영비·관리가 생김 → 서버 대신 Supabase(로그인·DB만)를 씀 |
| AI 요약·보고서 | 프로그램 서포터에는 이미 선택형 AI 다듬기가 있음. 나머지 둘은 규칙으로만 계산하는 것이 목적 |
| Storybook | 단일 HTML 파일 구조와 맞지 않음. 대신 브라우저 자동 테스트를 유지 |
