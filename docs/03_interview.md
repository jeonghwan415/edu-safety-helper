## **1\. 질문지**

[../PRD.md](../PRD.md)에서 **미확인·가설**로 남은 칸을 질문으로 바꿨습니다. 기본 7개 \+ 내 과제 추가 3개 \= 10개. 30분 분량입니다. (2026-11-12 고침: 현장 테스트 2차용)

| PRD 칸 | 기본 질문 | 내 과제에 맞게 고쳐 쓰기 |
| :---- | :---- | :---- |
| ① 누가 쓸까 | 이 일을 하는 분이 몇 명이고, 하루에 몇 번 하십니까? | 센터에서 6대 안전교육은 누가 맡고, 한 달에 몇 번 하십니까? 저학년·고학년·청소년이 같은 시간에 듣나요? |
| ② 뭐가 답답한가 | 가장 최근에 이 일 때문에 곤란했던 날을 처음부터 끝까지 말씀해 주세요. | 가장 최근 안전교육을 준비한 날, 주제를 정하는 것부터 일지를 다 쓸 때까지 처음부터 말씀해 주세요. |

| ④ 기능 3개 | 이 셋 중 하나만 된다면 어느 걸 고르시겠습니까? | 'TV에 바로 띄우는 수업', '한글 일지 자동 작성', '연간 계획표·이수 현황표' 중 하나만 남긴다면요? |
| ⑤ 어떻게 생겼나 | 지금 쓰시는 화면이나 엑셀을 그대로 보여주실 수 있을까요? | 센터에서 쓰는 프로그램일지·이수 현황 양식을 (아이 이름을 지우고) 보여 주실 수 있을까요? |
| ⑥ 성공의 모습 | 무엇이 달라지면 "이거 쓸 만하다"고 하시겠습니까? | 교육 1회 준비와 일지 작성에 지금 몇 분 걸리세요? 몇 분으로 줄면 계속 쓰시겠어요? |
| ⑦ 자료와 제약 | 받을 수 있는 샘플 자료는 무엇이고, 못 주시는 건 무엇입니까? | 센터 컴퓨터에 한글·크롬/엣지가 있나요? 유튜브가 막혀 있나요? TV 연결은 어떻게 하세요? |
| 추가 1 | | 지자체 점검 때 '수업 1회 = 1시간(1차시)'로 세는 방식이 인정되나요? 시간을 따로 적어야 하나요? |
| 추가 2 | | 청소년(중·고등) 아이들에게 지금 자료의 어느 부분이 어색했나요? (말투, 예시, 활동) |
| 추가 3 | | 성폭력·아동학대 수업에서 아이가 털어놓을 때 가장 어려웠던 점은 무엇이었나요? |

다 쓰고 1분만 다시 봅니다.

> * 네/아니오로 끝나는 질문은 고칩니다. "불편하신가요?"가 아니라 "어느 단계에서 가장 오래 걸립니까?"  
> * 내 아이디어를 설명하는 문장은 뺍니다. "제가 자동화하면 좋으시겠죠?"는 질문이 아닙니다.  
> * 내가 묻고 싶은 것을 묻지 말고, 상대가 하고 싶은 말을 듣습니다.
