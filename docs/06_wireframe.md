## 참고 사례

### 1. 현장 선생님 자작 PPT (아동권리헌장 · 약물 · 교통)

<details>
<summary>PPT 속 흐름 (글로 옮김)</summary>

* 아동인권: 표지 → 목차 → "권리가 뭐예요?" → 아동권리헌장 영상(보건복지부) → QUIZ 1~5번(헌장 2·3·7·8·9조 빈칸) → 활동지 '아동권리지킴이 약속' → 질의응답
* 약물: 생각톡톡 → 학습목표 2개 → 약물과 약 구분 → 의약품 구분 → 약의 양면성 → 사례톡톡 → 오용·남용 → 청소년 유해약물 → 마약류와 처벌 → 올바른 사용 → 퀴즈
* 교통: 학습목표 → 사고 원인 → 횡단보도 5단계 → 버스 이용 → 자전거 ABC 점검·헬멧 → 뒷좌석 안전띠 → 퀴즈

</details>

**화면 설명**
* 한 장에 한 가지 내용, 큰 그림 + 짧은 글, 퀴즈로 참여 유도

**내 과제에 주는 시사점**
* 모든 수업을 같은 흐름(표지 → 질문 → 약속 3개 → (영상) → OX → 활동 → 구호)으로 고정해 선생님이 익숙해지게
* 퀴즈는 '문제 → 정답' 2단계로 넘기고, 정답 화면에 해설까지

## 흐름

PRD 6장 화면 흐름 순서대로 적습니다. **첫 화면에서 클릭 1번이면 수업 화면**에 도착합니다(오늘의 추천).

### 1. 첫 화면

![첫 화면](images/06_wireframe/01_home.png)

**화면 설명**
* 맨 위 **⭐ 오늘의 추천 교육**: 주기가 가장 급한 영역의 주제와 이유(🔔 "올해 아직 한 번도 안 했어요"), 대상 버튼 4개 → 누르면 바로 수업 화면. 지난번에 고른 대상은 노란 테두리
* 올해 진행 ○ / 44회 막대, 교육 기록·연간 계획표·이수 현황표 버튼
* 영역 카드 6개(자리는 늘 같음) + 점선 테두리의 **＋ 추가 교육(아동인권)**
* 맨 아래 📜 법령 확인 기록(접힘)

**내 과제에 주는 시사점**
* "오늘 뭐 하지?"에 바로 답 → PRD 목표 '3번 클릭 안에 수업 화면'을 1번으로
* 카드 순서를 바꾸지 않아 40~50대 선생님이 헷갈리지 않게

### 2. 대상 고르기

![대상 고르기](images/06_wireframe/02_level.png)

**화면 설명**
* 🐣 저학년(초등 1~3) · 🦁 고학년(초등 4~6) · 🎧 청소년(중·고등) · 🤝 함께

**내 과제에 주는 시사점**
* 카톡 피드백("주제는 같게, 내용만 청소년에 맞게")으로 청소년 추가 (v0.9)

### 3. 주제 고르기

* 추가 수업이 있는 주제는 "수업 ○개 · 지진 폭설 …" 표시

![수업 화면](images/06_wireframe/05_lesson.png)

**화면 설명**
