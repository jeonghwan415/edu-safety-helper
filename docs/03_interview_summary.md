## 한눈에 보기

* **목적:** 배포한 도구가 현장에서 쓸 만한지 첫 반응 듣기
* **보는 사람:** 센터 선생님(교육 담당), 청소년센터 선생님
* **쓰는 사람:** 같은 사람 (선생님이 준비·발표·기록을 다 함)
* **가장 큰 고통:** 내용이 초등 위주라 청소년에게 어색함, 내용이 더 알찼으면 함
* **결과물:** 칭찬(디테일, 양식 맞음) + 보완 요청 2가지(청소년, 내용 보강)
* **환경:** 휴대폰 카카오톡으로 링크를 열어 봄 → 센터 PC·TV 환경은 미확인

## 질문별 정리

### 1. 전체 인상

* 여러 선생님이 함께 보고 "너무 잘 만들었다", "엄청 디테일하다"고 함
* "센터 양식에 잘 맞는다"(현장 테스트 1차)

### 2. 아쉬운 점

* "내용만 알차진다면" → 수업 내용의 깊이가 부족하게 느껴짐
* OX 정답 해설, 주제마다 영상 (현장 테스트 1차)

### 3. 청소년센터에서 쓰려면

* "안전교육이라 **주제는 동일**해야 하고 **내용만 청소년에 맞게** 구성"
* `[정리 주]` 별표 6에는 청소년용 항목이 따로 없어서, 초등 주제를 그대로 두고 내용만 바꾸는 방식이 지침과도 맞음
