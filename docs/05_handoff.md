# **05 handoff**

**개인 프로젝트**  
과제명: 6대 의무교육 도우미 (가칭) · 기준: v0.9 (2026-11-12)  
개발을 이어서 하기 전에 정해 둔 것. 모르는 것은 **미확인**으로 적고 [03 인터뷰](03_interview.md) 질문으로 옮깁니다.

- 저장 위치 > **교육 기록은 선생님 컴퓨터의 브라우저(localStorage)에만** 저장 (`seh-records-v1` 기록, `seh-prefs-v1` 장소·진행자·담당자·마지막 대상). 서버·DB 없음. 브라우저를 정리하면 지워질 수 있어서, 기록 3건 이상 + 30일 넘게 백업 안 하면 첫 화면에 백업 알림. 백업은 기록 파일(.json) 내보내기/불러오기
- 권한 > 로그인 없음. 사이트는 누구나 열 수 있고, 기록은 그 컴퓨터에서만 보임. 여러 선생님이 함께 쓰는 서버 기능은 이번 버전에서 하지 않음
- API·DB > 외부 API 없음. 데이터는 `data/areas.json`(원본) 하나 → `npm run data`로 `areas.js` 생성. 유튜브는 공식 기관 영상만 youtube-nocookie로 재생, 끝나면 추천 영상을 가림. 폰트(Jua)만 Google Fonts
- 실패 조건 >
  - 유튜브가 막히거나 8초 안에 안 열리면 영상 장이 "🔗 유튜브에서 열기" 큰 버튼으로 바뀜(새 창). 영상 장 아래에도 늘 링크가 있음
  - 파일로 열면(file://) 영상은 유튜브 링크로 대신 열림
  - 저장이 막힌 브라우저면 "저장하지 못했어요" 알림 → 복사 버튼으로 내용 보관
  - 활동지·PPT 생성 컴퓨터에 Edge·Chrome이 없으면 `npm run browser` 안내가 나옴
  - AI가 쓴 수업 내용은 모두 "검토 필요" 표시 (사람이 검토 후 "검토 완료"로 바꿈)
- 개인정보 > 아이 이름은 선택 입력, 기록에만 저장. GitHub에는 기록이 올라가지 않음. 'AI에게 부탁하기'는 글만 만들고 "아이 이름은 적지 마세요" 안내
- 저작권 > **이용 조건: 수업 자료 CC BY-NC-SA 4.0, 코드 MIT, 만든 사람 jeonghwan0415** ([../LICENSE.md](../LICENSE.md), 사이트 "이용 안내·저작권" `#about`, 모든 쪽 아래·PPT·활동지에 출처). 외부 자료는 링크만(내용 복사 금지), 그림은 직접 만든 SVG·이모지 + 청소년은 Tabler 선 아이콘(MIT), 실존 캐릭터 금지. docs의 현장 PPT 3개는 **공개 저장소에 올리지 않음**(.gitignore)
- 아동 보호 > 성폭력·아동학대 수업은 자극적 묘사 금지, 피해 아동 탓 금지, "말해줘서 고마워, 네 잘못이 아니야", 선생님은 신고의무자(112) 안내 유지
- 법 기준 > 「아동복지법」 제31조(2025.10.2 시행 개정 반영), 시행령 제28조 별표 6(2022.6.21 개정본이 현행). 첫 화면 "법령 확인 기록"에 확인일과 함께 적어 둠. 법이 바뀌면 사람이 원문을 보고 고침
- 배포 > main 브랜치에 올리면 GitHub Actions가 GitHub Pages로 자동 배포 (1~2분). 주소가 2026-11-11에 `edu-safety-helper`로 바뀌어 옛 주소는 열리지 않음
