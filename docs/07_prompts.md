## 1. 잘 통했던 요청 방식

| 방식 | 예 | 왜 좋았나 |
| :---- | :---- | :---- |
| 자료 위치를 알려 주기 | "docs에 자료를 추가했어 참고할 만한 자료를" | AI가 먼저 읽고 반영함 (PPT 3종 → 아동인권·약물·교통 수업) |
| 역할을 주고 '분석 + 대안'을 같이 묻기 | "너가 디자인 개발자라면 수정하고 싶은 사항을 3가지 분석하고 대안을 말해줘" | 바로 고치지 않고 먼저 제안 → 내가 골라서 시킴 |
| 고를 것만 고르기 | "첫번째랑 세번째꺼 보완해줘" | 범위가 작아져 결과 확인이 쉬움 |
| 현장 피드백을 그대로 붙이기 | 카톡 캡처 2장 | 해석 없이 원문을 주니 정확하게 반영됨 |
| 확인 후 올리기 | "내가 먼저 확인한 다음에 승인되면 깃허브에 올려줘" | 공개 사이트에 바로 반영되는 걸 막음 |
| 이유 묻기 | "왜 못 만들었는지 이야기해주고 … 어떻게 해결할지 보고" | 원인(브라우저 없음)과 해결(npm run browser)을 함께 받음 |

**아쉬웠던 점:** "docs에 피드백 1, 2가 있다"고 했지만 실제로는 카톡 캡처였어요 → **파일이 어디 있는지(카톡·휴대폰·PC)** 같이 말해 주면 한 번에 찾아요.

## 3. 프로그램 안의 프롬프트 — 'AI에게 부탁하기' 부탁 글

선생님이 고른 상황으로 `index.html`의 `aiPrompt()`가 만드는 글입니다. **프로그램은 AI를 부르지 않고** 이 글만 복사합니다. (뼈대, `{ }`는 자동으로 채워짐)

```
저는 지역아동센터 선생님이에요. 아래 안전교육 수업안을 우리 센터 상황에 맞게 바꾸고 싶어요.

[교육] {영역} – {주제} ({대상})
[우리 센터 상황]
- {체크한 상황: 저학년과 고학년이 함께 / 교실이 좁음 / 집중 시간이 짧음 / 인원 적음·많음 / 한국어가 서툰 아이 / 20분밖에 없음}
[부탁] {수업 흐름 다시 짜기 | 새 활동 2가지 | 새 O X 퀴즈 4문항}

[지켜 주세요]
- 「아동복지법」 시행령 별표 6의 주제("{주제}")는 바꾸지 말아 주세요.   (아동인권은 "유엔아동권리협약·아동권리헌장에 맞게")
- 아이들 눈높이의 쉬운 말로, 한 문장은 짧게 써 주세요.
- 신고·상담 번호는 112, 129, 182, 117, 1342, 119 중 맞는 것만 쓰고, 새 번호를 만들지 말아 주세요.
- (성폭력·아동학대·아동인권) 자극적이거나 구체적인 피해 묘사는 넣지 말고, 피해 아동을 탓하는 말은 쓰지 말아 주세요. "말해 줘서 고마워, 네 잘못이 아니야"를 지켜 주세요.
- 무섭게 겁주는 방식이 아니라, 할 수 있는 행동을 알려 주는 방식으로 써 주세요.

[지금 수업안]
{목표, 수업 흐름, 준비물, 슬라이드, 안전 주의}
```
