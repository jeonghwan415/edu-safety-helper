  - 3번 클릭 안에 수업 화면에 도착하는지, 일지 쓰는 데 몇 분 걸리는지, "다음에도 쓰겠다"는지

## 2. 검토할 때 보는 것

| 항목 | 확인할 내용 |
|---|---|
| 내용이 맞는지 | 행동요령이 공식 기준과 같은지, 퀴즈 O/X 정답과 이유, 신고 번호(112·117·119·182·129·1342)가 맞는 곳에 쓰였는지 |
| 아이에게 안전한지 | 무섭거나 자극적인 말이 없는지, 피해 아이를 탓하는 말이 없는지, 우리 센터 아이에게 상처가 될 예시가 없는지 |
| 수준이 맞는지 | 저학년이 알아들을 말인지, 고학년에게 너무 쉽지 않은지, 활동이 센터 공간·인원으로 가능한지 |
| 영상 | 끝까지 보고 괜찮은지, 길이가 수업 시간에 맞는지 |
| 활동지 | 인쇄해서 글씨 크기, 문제가 잘 되는지 |

**검토 완료로 바꾸는 방법**
1. `data/areas.json`에서 해당 수업의 `"status": "검토 필요"`를 `"검토 완료"`로 고쳐요.
2. 데이터를 반영해요 (아래 3번 참고).
3. 내용을 고쳤다면 활동지·PPT도 다시 만들어요.

## 3. 자주 쓰는 방법

**데이터 반영 (areas.json을 고친 뒤 항상)**
- VS Code 메뉴 **터미널 → 작업 실행 → "1. 데이터 반영"**
- 또는 터미널(`Ctrl` + `` ` ``)에 붙여넣기:
  ```
  cd /d "C:\Users\SAMSUNG\OneDrive\바탕 화면\천안ax\safety-edu-helper" && npm run data
  ```
- "데이터 검사 통과"가 나오면 성공

**화면 확인**: VS Code 오른쪽 아래 **Go Live** → `http://127.0.0.1:5500`

**GitHub에 올리기**: 왼쪽 **소스 제어**(나뭇가지 아이콘) → 설명 한 줄 → **커밋** → **동기화**. 1~2분 뒤 사이트에 자동 반영. (또는 Claude에게 "깃허브에 올려줘")
