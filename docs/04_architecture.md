**개인 프로젝트**  
과제명: 6대 의무교육 도우미 (가칭) · 기준: v0.9 (2026-11-12)  
PRD의 핵심 기능을 입력 → 처리 → 출력으로 나눠 봅니다. **규칙으로 할 일과 AI에게 맡길 일을 구분합니다.** 파일·함수 이름은 [../CLAUDE.md](../CLAUDE.md)에 더 자세히 있어요.

핵심 기능:  
1\. 수업 찾기·진행 ─ 영역 → 대상 → 주제 3번 클릭 → 수업 화면·발표 모드(TV) → \[data/areas.json의 수업 데이터 그대로\]  
2\. 교육 기록·일지 ─ 날짜·인원만 입력 → 진행내용·의견 초안 자동 작성(규칙) → 한글(.hwpx) 프로그램일지  
3\. 연간 관리 ─ 기록을 모아 → 44회 진행표·주기 알림·오늘의 추천·연간 계획표·이수 현황표  

| 기능 | 화면 (06 와이어프레임) | 입력 | 처리 | 출력 |
| ----- | ----- | ----- | ----- | ----- |
| 수업 찾기·진행 | ① 첫 화면 ② 대상 ③ 주제 ④ 수업 고르기 ⑤ 수업 화면 ⑧ 발표 | 영역, 대상(저학년·고학년·청소년·함께), 주제 | 별표 6 주제 30개 + 추가 수업, 대상별 수업 데이터 찾기(청소년 자료 없으면 고학년 자료). 글 넘치면 자동 축소 | 슬라이드(1600×900), 수업 흐름·대본·상황 장면·배경지식, 활동지 PDF, 선생님용 PPT, 공식 영상·자료 링크 |

## 구조 그림

```
[선생님 브라우저 (센터 PC · Edge/Chrome)]
   index.html  ← 프로그램 전체 (HTML+CSS+JS 한 파일, 외부 라이브러리 없음)
     ├─ data/areas.js        수업 데이터 (areas.json에서 자동 생성)
     ├─ data/hwpx-template.js 한글 일지 빈 양식
     ├─ img/  worksheets/  slides/   그림 · 활동지 PDF · PPT
     └─ localStorage          교육 기록·설정 (이 컴퓨터 브라우저에만)
             │ 파일 받기
             ▼
        .hwpx 일지 / 기록 백업(.json)

[작성자 PC · VS Code (만들 때만)]
   data/areas.json (★원본) ─ npm run data ─→ data/areas.js (+ 검사: 44시간, 슬라이드 번호, 그림, OX 정답)
                           ─ npm run cards ─→ img/*.svg (이모지 그림 카드)
                           ─ npm run worksheets ─→ worksheets/*.pdf·png   (브라우저 필요)
                           ─ npm run slides ─→ slides/*.pptx             (브라우저 필요)
   npm run browser : Edge·Chrome 없는 컴퓨터에 전용 크롬 받기
   git push main ─→ GitHub Actions ─→ GitHub Pages (https://jeonghwan415.github.io/edu-safety-helper/)
```

## 규칙 vs AI

| 규칙(코드·데이터)으로 하는 일 | AI에게 맡기는 일 |
| :---- | :---- |
| 별표 6 영역·주기·시간·주제 (AI가 만들지 않음) | 수업 문장 초안 작성 — **개발할 때만** Claude Code가 쓰고 `status: "검토 필요"`로 넣음 → 사람이 검토 |
| 수업 흐름 시간(5·10·10·10·5분), 슬라이드 순서, 진행내용·의견 초안 | 우리 센터 맞춤 변경 — 선생님이 '부탁 글'을 복사해 직접 AI에 붙여 넣음 |
| 44회 계산, 주기 알림, 오늘의 추천, 계획표 배치 | — |
| 신고 번호는 확인된 것만 (112·129·182·117·1342·119·1388·1336) | — |

**운영 중 프로그램은 AI를 부르지 않아요.** 비용이 들지 않고, 아이 정보가 밖으로 나가지 않아요.
