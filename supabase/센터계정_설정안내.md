# 센터 계정(B) 설정 안내 — 관리자(센터장)용, 한 번만

프로그램 서포터 · 6대 의무교육 도우미 · 차량 지킴이는 **두 가지 방식**으로 쓸 수 있어요.

| | A. 이 컴퓨터에만 저장 (지금 기본) | B. 센터 계정 |
|---|---|---|
| 하는 일 | 연 컴퓨터의 브라우저에만 기록이 남음 | 어느 컴퓨터·휴대폰에서든 로그인하면 우리 센터 기록이 보임 |
| 필요한 것 | 없음 | 무료 Supabase 프로젝트 1개 (세 프로그램이 함께 씀) |
| 좋은 점 | 비용 0원, 아동 정보가 밖으로 나가지 않음 | 컴퓨터를 바꿔도 기록이 남음, 선생님 여러 명이 함께 씀, 누가 언제 고쳤는지 남음 |
| 주의할 점 | 다른 컴퓨터와 이어지지 않음 | 아동 정보가 서버에 저장됨 → **개인정보 처리방침·보호자 동의** 필요, 계정 관리 필요 |

- 서버 정보를 넣지 않으면 프로그램은 지금처럼 **A로 동작**해요. B는 켜고 싶을 때만 켜면 돼요.
- B로 바꿔도 **아동 사진·첨부 파일은 서버에 올라가지 않고** 넣은 컴퓨터에만 남아요. AI 키, 화면 설정(글자 크기·밝기)도 그 컴퓨터에만 남아요.
- 무료 요금제의 한도·정책(오래 안 쓰면 일시 정지 등)은 바뀔 수 있어요. 시작 전에 https://supabase.com/pricing 을 확인해 주세요.

## 1. Supabase 프로젝트 만들기 (10분)

1. https://supabase.com 에 센터 메일(또는 GitHub)로 가입해요.
2. **New project** → 이름 `center-programs`, 데이터베이스 비밀번호는 길게 정하고 따로 적어 두기, Region은 **Northeast Asia (Seoul)** → **Create**.
3. 1~2분 기다리면 프로젝트가 만들어져요.

## 2. 데이터베이스 설정 (복사 → 붙여 넣기 → Run)

1. 왼쪽 메뉴 **SQL Editor** → **New query**
2. 이 폴더의 `schema.sql` 내용을 **전체 복사**해서 붙여 넣고 **Run**
3. 아래에 `Success`가 나오면 끝. (여러 번 실행해도 괜찮아요)

이 SQL이 해 주는 것

- 같은 센터 선생님만 그 센터 기록을 봄 (행 단위 보안, RLS)
- 센터에 들어오려면 **초대 코드(8자리)** 필요. 틀린 코드는 15분에 10번까지
- 지운 기록도 '지운 표시'로 남겨서 다른 컴퓨터에도 지운 것이 전달됨
- 누가 언제 무엇을 추가·수정·삭제했는지 1년 동안 자동 기록

## 3. 로그인 설정

1. **Authentication → Sign In / Providers → Email**: 켜져 있는지 확인. **Confirm email**(가입 확인 메일)은 켜 두기를 권해요.
2. 같은 화면에서 비밀번호 최소 길이를 **8**로 바꿔요. (프로그램도 8자 이상, 숫자+글자를 요구해요)
3. **Authentication → URL Configuration**
   - Site URL: `https://jeonghwan415.github.io/program-supporter/`
   - Redirect URLs에 세 개 추가:
     - `https://jeonghwan415.github.io/program-supporter/`
     - `https://jeonghwan415.github.io/edu-safety-helper/`
     - 차량 지킴이를 웹 주소로 쓰면 그 주소 (파일판·구글 시트판은 메일 링크 대신 [로그인]으로 들어오면 돼요)

## 4. 주소와 공개 키를 프로그램에 넣기

**Project Settings → API**(또는 Data API · API Keys)에서 두 가지를 복사해요.

- **Project URL** (예: `https://abcd1234.supabase.co`)
- **anon public** 키 (`eyJ…`로 시작하는 긴 글자). 공개용이라 화면·GitHub에 있어도 괜찮아요.
- ⚠️ **service_role** 키는 절대 넣지 마세요. (모든 보안을 건너뛰는 관리자 키예요. 프로그램도 넣으면 막아요)

넣는 곳 (둘 중 하나)

| 방법 | 어떻게 | 언제 |
|---|---|---|
| **코드에 넣기 (권장)** | 프로그램 서포터·6대 의무교육 도우미는 `index.html`, 차량 지킴이는 `프로그램/소스/src/page.html`의 `window.CENTER_CLOUD_CONFIG = { url: "", anonKey: "" };`에 붙여 넣고 GitHub에 올리기. 차량 지킴이는 `프로그램/소스`에서 `node build.js`를 한 번 돌린 뒤 `build/차량지킴이.html`을 복사 | 모든 선생님이 따로 넣지 않아도 됨 |
| 화면에서 넣기 | 프로그램 오른쪽 위 **[이 컴퓨터에만 저장]** 단추 → 서버 연결 창에 붙여 넣기 | 먼저 시험해 볼 때 (그 브라우저에만 저장) |

## 5. 센터 만들기 → 선생님 초대

1. 센터장: 오른쪽 위 **[이 컴퓨터에만 저장]** → **처음이에요(가입)** → 메일함에서 확인 링크 → 로그인
2. **우리 센터 새로 만들기** → 센터 이름, 내 이름, **개인정보 안내 확인란** 표시 → 센터 만들기
3. 이 컴퓨터에 있던 기록이 있으면 **합치기 / 합치지 않기(파일로 받기)**를 물어요.
4. 머리말 단추가 **"○○센터 · 함께 저장"**으로 바뀌면 끝. 단추를 누르면 **초대 코드**가 보여요.
5. 선생님: 같은 방법으로 가입 → **초대 코드로 들어가기** → 코드와 이름 넣기

세 프로그램 모두 **같은 이메일·비밀번호**로 로그인해요. 같은 주소(`jeonghwan415.github.io`)에서 여는 프로그램끼리는 한 번 로그인하면 이어지고, 프로그램마다 센터를 한 번씩 골라요.

## 6. 운영할 때

- **그만둔 선생님**: 센터 창 → 선생님 목록에서 **내보내기** → **새 코드 만들기**
- **공용 컴퓨터**: 다 쓰면 **로그아웃**. 로그아웃하면 그 컴퓨터에 받아 둔 센터 기록을 지워요.
- **인터넷이 끊기면**: 단추가 "연결 끊김"으로 바뀌고, 적은 기록은 그 컴퓨터에 보관했다가 연결되면 보내요.
- **같은 기록을 두 곳에서 동시에 고치면**: 나중에 보낸 쪽 내용이 남아요. 누가 고쳤는지는 센터 창 **최근에 고친 기록**에서 볼 수 있어요.
- **백업**: Supabase 대시보드 **Table Editor → center_data → Export to CSV**, 또는 각 프로그램의 백업 파일 받기를 가끔 해 두세요.
- **개인정보**: 센터 개인정보 처리방침에 "프로그램 기록을 Supabase(클라우드) 서버에 보관"을 적고, 필요하면 보호자 동의를 받아 주세요.

## 7. 비밀번호를 잊었을 때

로그인 창 **비밀번호를 잊었어요** → 메일 링크 → 프로그램이 열리면 새 비밀번호를 정해요.

### 만든 것 (개발용)

| 파일 | 내용 |
|---|---|
| `schema.sql` | 표 5개(centers · center_members · center_data · center_history · join_attempts), RLS, 함수(my_centers · create_center · join_center · center_people · center_recent · set_my_name · rotate_invite · remove_member · leave_center) |
| 프로그램 안 `center-cloud v1.0` 블록 | 세 프로그램이 똑같이 쓰는 공통 코드. 라이브러리 없이 `fetch`로 Supabase Auth·REST를 부름. 고칠 때는 세 곳을 같이 고쳐요 |

기록 맞추는 방법: 프로그램이 원래 쓰던 `localStorage` 칸을 그대로 두고, 그 칸이 바뀌면 1초 뒤 서버로 보내고(바뀐 줄만), 20초마다·창으로 돌아올 때 서버에서 바뀐 줄만 받아요. 계획서·교육 기록은 **하나에 한 줄**이라 서로 다른 계획서를 동시에 고쳐도 섞이지 않아요.
