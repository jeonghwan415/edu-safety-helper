# 6대 의무교육 도우미

지역아동센터 선생님이 영역과 학년만 고르면, 아이들에게 띄울 시각자료·40분 수업안·활동지·공식 자료를 한 화면에서 보여주는 프로그램이에요.

## 인터넷 주소로 쓰기 (GitHub Pages)

GitHub에 올리면 자동으로 배포돼요. 주소는 저장소 **Settings → Pages**에 나와요.
설치 없이 주소만 알려 주면 다른 센터 선생님도 바로 쓸 수 있어요. 기록은 각자 컴퓨터의 브라우저에만 저장돼요.

## VS Code에서 실행하기

1. VS Code에서 이 폴더(`safety-edu-helper`)를 열어요.
2. 오른쪽 아래 파란 막대의 **Go Live**를 눌러요.
3. 브라우저가 `http://127.0.0.1:5500` 으로 열리면 끝이에요.
   - 이렇게 열면 유튜브 영상이 화면 안에서 바로 재생돼요.
   - 파일을 고치고 저장하면 브라우저가 저절로 새로고침돼요.
4. 끌 때는 같은 자리의 **Port : 5500** 을 눌러요.

> `index.html`을 더블클릭해서 열어도 되지만, 그때는 유튜브 영상이 새 창으로 열려요.

## 데이터를 고치거나 자료를 다시 만들 때

처음 한 번만 VS Code 터미널(<kbd>Ctrl</kbd>+<kbd>`</kbd>)에서 `npm install` 을 실행해요. (이 컴퓨터에는 이미 해 뒀어요)
이 폴더의 VS Code 터미널은 PowerShell 대신 **명령 프롬프트(cmd)** 로 열리게 설정해 뒀어요. PowerShell에서 `npm`이 "스크립트를 실행할 수 없습니다" 오류를 내기 때문이에요.
그다음부터는 터미널 명령이나 VS Code 메뉴 **터미널 → 작업 실행**에서 골라 실행하면 돼요.

| 명령 | 하는 일 |
|---|---|
| `npm run data` | `data/areas.json`을 고친 뒤 꼭 실행 (프로그램에 반영 + 오류 검사) |
| `npm run cards` | 새 슬라이드 그림 카드 만들기 |
| `npm run worksheets` | 활동지 PDF 다시 만들기 |
| `npm run slides` | 선생님용 PPT 다시 만들기 |
| `npm run build` | 위 4개 한 번에 |

일부만 만들 때: `npm run slides -- --only=abuse-e-03-high`

> AI(Claude Code, Copilot)에게 작업을 맡길 때는 `CLAUDE.md`를 먼저 읽게 하면 돼요. 프로젝트 구조와 지켜야 할 규칙이 정리되어 있어요.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 프로그램 화면 (첫 화면 → 대상 → 주제 → 수업 화면 → 발표 모드) |
| `data/areas.json` | ★ 원본 데이터 (별표 6 시간·주기·세부 항목, 60개 수업 내용) — 여기만 고쳐요 |
| `data/areas.js` | 프로그램이 읽는 파일 (`npm run data`로 자동 생성) |
| `data/hwpx-template.js` | 한글 프로그램일지 빈 양식 |
| `tools/` | 자료 자동 생성 도구 |
| `CLAUDE.md` | AI용 프로젝트 안내 (구조·데이터 형식·규칙) |
| `img/<주제id>/` | 슬라이드 그림 (SVG) |
| `worksheets/` | 인쇄용 활동지 78개 (PDF, 미리보기 PNG, 원본 HTML) |
| `slides/` | 선생님용 PPT 78개 |
| `docs/교육지침.png` | 운영지침 별표 6 |
| `PRD.md` | 기획 문서 |

## 수업 내용 고치는 법

1. `data/areas.json`에서 주제 id(예: `abuse-e-03`)를 찾아 `content.low`(저학년) 또는 `content.high`(고학년)를 고쳐요.
2. 검토가 끝나면 `"status": "검토 필요"`를 `"검토 완료"`로 바꿔요.
3. `npm run data` → 필요하면 `npm run worksheets -- --only=abuse-e-03` , `npm run slides -- --only=abuse-e-03`
